# Privacy design

SeeRay Lens defaults to data minimisation, explainability and reversibility.

- Consent gating supports accept, decline, withdrawal and asking again later.
- URLs are minimised; raw IP addresses, advertising IDs and device models are not collected.
- Anonymous identifiers are site-scoped, while workspace members and API tokens follow explicit permissions.
- Location, heatmaps, recordings, experiments and crash collection require explicit configuration.
- Retention, exports and audit history make the data lifecycle visible.
