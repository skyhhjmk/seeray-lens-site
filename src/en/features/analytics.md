# Analytics

Install the Tracker to collect page views, then opt into events, goals, downloads, outlinks, search, content interactions and Core Web Vitals. The same versioned collector schema serves Web and native SDKs.

Reports include live visits, pages, acquisition, technology, locations, page flows, heatmaps, recordings, goals, funnels, attribution, experiments, segments, cohorts, dashboards, exports, scheduled reports and alerts.

Heatmaps and recordings are disabled by default and have independent sampling, retention and consent boundaries. Inputs are masked and DOM snapshots exclude scripts and canvas capture.
