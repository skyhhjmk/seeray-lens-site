# Capabilities

SeeRay Lens connects collection, analysis and action in one self-hosted workspace.

| Area | What it covers |
| --- | --- |
| Analytics | Overview, pages, events, acquisition, technology, locations, live visits, search and Web Vitals |
| Behaviour | Heatmaps, session recordings, page flows, forms, media, crashes and content interactions |
| Growth | Goals, funnels, attribution, experiments, audience segments and cohorts |
| Collaboration | Saved dashboards, exports, scheduled reports, alerts, annotations and audit history |
| Developer tools | Web Tracker, Android/iOS/Flutter SDKs, API tokens, extensions and Tag Manager |

Read more about [analytics](/en/features/analytics) and [privacy](/en/features/privacy).
