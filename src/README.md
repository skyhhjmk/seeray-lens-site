## 一个更安静、更诚实的分析工具

SeeRay Lens 不把用户变成广告画像，也不要求你把业务数据交给第三方平台。它提供产品团队每天真正需要的答案：用户从哪里来、看了什么、在哪里离开，以及什么体验正在变好。

项目的大多数产品设计、代码实现和文档整理由 GPT 辅助完成，并由项目维护者负责取舍、审查和验证。

<div class="home-grid">

### 面向产品团队

保存仪表盘、创建细分人群、比较周期、追踪目标和漏斗。报告不是一堆 JSON，而是可以直接用于讨论和决策的视图。

### 面向工程团队

Web Tracker、Android、iOS 与 Flutter SDK 共用版本化采集协议；RabbitMQ 异步摄取，PostgreSQL 持久化，部署边界清楚。

### 面向隐私负责人

同意前不采集，支持拒绝与撤回；不保存原始 IP，不依赖广告标识符；热图、录屏和位置能力都需要显式启用。
