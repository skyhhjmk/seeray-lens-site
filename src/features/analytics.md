# 分析能力

## 从一个页面浏览开始

安装 Tracker 后，SeeRay Lens 会在站点级别记录页面浏览，并可按需启用事件、目标、下载、外链、站内搜索、内容交互和 Core Web Vitals。URL 会做最小化处理，采集协议同时服务 Web 与原生 SDK。

## 报表不止是 PV

- 实时访问：查看活跃访问、最近页面与动作轨迹。
- 行为分析：页面流、入口/退出页面、热图与录屏。
- 增长归因：UTM、搜索/社交/AI 助手来源、首触点/末触点与多触点模型。
- 产品决策：目标、漏斗、实验提升度、受众细分和 cohort 留存。
- 团队协作：可视化仪表盘、导出、定时报表、告警和站点注释。

## 热图和录屏是可控的增强能力

它们默认关闭，并拥有独立的采样率、留存和同意边界。输入值会被遮罩，脚本和 canvas 不进入 DOM 快照；适用的站点必须先完成隐私评估，再决定是否启用。
