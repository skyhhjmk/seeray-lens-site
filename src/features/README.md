# 产品能力

SeeRay Lens 把“采集、理解、行动”放在同一个自托管工作区里。

## 能力地图

| 方向 | 你能得到什么 |
| --- | --- |
| 分析报表 | 概览、页面、事件、来源、技术、地域、实时访问、站内搜索与 Web Vitals |
| 行为洞察 | 热图、会话录屏、页面流、表单、媒体、崩溃与内容交互 |
| 增长分析 | 目标、漏斗、归因、成本导入、实验、受众细分与 cohort |
| 运营协作 | 保存仪表盘、CSV/JSON/PDF 导出、定时报表、告警、注释与审计日志 |
| 开发者工具 | Web Tracker、Android/iOS/Flutter SDK、API Token、扩展与 Tag Manager |

## 为什么选择自托管？

自托管不只是“换一个部署方式”。它让数据生命周期、访问边界、备份策略和成本曲线都变得可解释。SeeRay Lens 以工作区和站点为隔离边界，配合成员角色、令牌权限和留存策略，适合希望拥有完整数据控制权的团队。
